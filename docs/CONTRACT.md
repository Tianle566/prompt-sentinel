# Integration contract

Project root is `/Users/hw/毕设`. Python imports use `backend.app...`.

Root owns core/config.py, API, database, download/smoke scripts, README/start scripts/docs. Detection agent owns detectors/, defense/, llm/, services/detection.py, services/pipeline.py and schemas.py plus own tests. Dataset agent owns scripts/build_dataset.py, scripts/run_eval.py, services/evaluation.py (if needed), data generation and evaluation tests. Frontend agent owns frontend/ exclusively.

`backend.app.core.config`: ROOT: Path; get_config() -> dict (deepcopy); resolve_path(str) -> Path rooted at project; save_config(dict) -> dict. Default keys in backend/config.yaml. Config uses lowercase l1..l5, detector results uppercase L1..L5.

Core schemas Pydantic: LayerResult(layer, enabled, is_attack: bool|None, score: float|None, status: ok|disabled|error, categories: list[str], rule_ids: list[str], latency_ms: float, details: dict, error: str|None); DetectionResult(is_attack, layer_results: list[LayerResult], latency_ms, strategy, reliable: bool); PipelineResult(output, blocked, detection, output_check: LayerResult|None, hardening: LayerResult|None, latency_ms, error: str|None, session_id).

DetectionService(config: dict|None).detect(text) -> DetectionResult. Models lazy-loaded local-only. `.guard` usable to moderate outputs, document details in final agent report. PipelineService(config: dict|None).process(text, protected=True, session_id=None, original_task=None) -> PipelineResult. TargetLLM(config).generate(messages) -> str, .health() -> dict. Pipeline sessions have random canaries that survive requests per session. Rule detector never presented as a substitute for ML inference; missing models/errors are explicit and fail-closed for protected traffic.

Eval entrypoint `scripts.run_eval.run_evaluation(config=None, experiment='all', limit=None, asr_limit=None, progress_callback=None, output_dir=None)` -> JSON-serializable summary. Callback `(progress: float 0..100, message: str)`. Supports all/detection/defense/ablation/overhead; optionally also 1/2/3/4 CLI aliases. Config snapshot per evaluation. No remote attacks: target loopback URL required for all ASR/attack experiments.

REST contract at `/api`, JWT Bearer. Errors FastAPI `{detail: str}`. POST auth/login JSON `{username,password}` -> `{access_token,token_type,user:{id,username,role}}`. GET auth/me -> user. GET health public -> `{status,models:{deberta,qwen_guard,target},target,device}`. POST chat `{text,protected:true,session_id?}` -> PipelineResult + id. POST chat/compare same -> `{unprotected: PipelineResult,protected: PipelineResult}`. POST detect `{text}` -> DetectionResult. GET attack/samples?attack_type=&limit= -> `{items: samples,total}`. POST attack/run `{texts?:string[],sample_ids?:string[],protected:true}` -> `{items:[{text,attack_type,blocked,success:bool|null,result:PipelineResult}],total}`. POST document/summarize multipart `file` txt, `protected` boolean -> `{filename,paragraphs:[{index,text,is_attack,detection}],result:PipelineResult}`. GET logs?page=1&page_size=20&attack_type=&layer=&start=&end= -> `{items,total,page,page_size}`; GET logs/{id} -> full log. GET stats -> `{total_requests,blocked_requests,block_rate,average_latency_ms,attack_types:[{name,value}],daily:[{date,total,blocked}],layers:[{name,value}],latencies:[{name,value}]}`. GET config -> full config sanitized auth/no secrets; PUT config admin -> full updated policy. Editable sections layers/fusion/target (nonsecret subset), updates effective immediately. GET eval/datasets -> `{items:[{id,name,count,path}]}`. POST eval/jobs admin `{experiment:'all',limit?,asr_limit?,dataset?:'detect'|'asr',config?:{layers?,fusion?}}` -> job. GET eval/jobs -> `{items:job[]}`. GET eval/jobs/{id} -> job `{id,status:queued|running|completed|failed,progress,message,result?,error?,created_at}`. GET eval/artifacts/{job_id}/{filename} authenticated for generated csv/png/json only; frontend axios blob preview/download.

Eight Vue pages: login, chat compare, attack console, document summary, logs, ECharts dashboard, admin policy, evaluation center. Display real loading/error/empty states. No mock API results or invented metrics. Frontend default Vite port 5173 proxy /api -> localhost:8000. Chinese UI polished restrained security console in warm white/teal/navy with clear typography. Login credentials displayed only if root supplies bootstrap credentials file, not hardcoded prod passwords.
