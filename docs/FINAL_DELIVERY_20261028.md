## 论文与实验对应

论文主实验仍来自Apple M1 CPU协议，检测样本1116条、攻击样本200条×9种策略。合并来源标签F1为0.7834，无五层防护与完整防护的协议ASR分别为52.0%和0.5%。ASR表示攻击成功率。

20组模拟办公材料的120次真实TXT上传独立保存。两个保护策略均观察到0/20严格整答劫持，同时误拒8/20正常文档。论文保留这一代价，以及部分披露漏检、合法引用误报和AI复核局限。没有新增训练或微调，工程集成不写作新基础模型。

交付副本的正文为双栏、小四宋体与Times New Roman，标题黑体、文字黑色；摘要与目录通栏，宽表和图示跨栏以保留可读性。论文11个展示公式均为可编辑Word公式，文中参考文献引用为上标；开题保留3个原生公式。目录通过原生Word刷新，原稿单独保留。

## 本机检查命令

从仓库根目录执行，先安装依赖和准备文件：

```powershell
.\start.bat --check
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe scripts/smoke_test.py --device cpu
```

第三项需要Ollama服务已启动，会真实加载模型。默认写入新的`results/smoke_<时间>_<随机后缀>/`；指定`--output-dir`时，已有同名报告会被拒绝覆盖。`verify_system.py`同样默认新建报告目录，支持`--credentials-file`为独立验收服务提供本机凭据。它会创建请求、策略审计及评测记录，使用前选好目标服务和数据库。

前端在`frontend/`运行`npm ci`、`npm run build`。离线检查与自动测试、真实模型抽查分别保存，不能相互替代。

复核原论文数字无需启动模型：

```powershell
.\.venv\Scripts\python.exe scripts/audit_results.py results/thesis_v2_20261022 --data-dir data/frozen/thesis_v2_20261022 --report results/my-new-audit/independent-audit.json
```

每次换一个新报告路径。重新推理时另建结果目录并固定完整协议，原Mac路径仅作为历史元数据保留。
