# 项目检查与优化记录（2026-10-28）

本轮先检查代码、启动脚本、现有测试与前端构建，再针对可复现问题修改。检查基线为311项测试通过、1项集成测试排除，前端构建成功。以下验证在Windows本机完成。

## 修复与改进

| 范围 | 检查发现 | 完成的修改 |
| --- | --- | --- |
| 安装恢复 | Windows只在首次创建虚拟环境时安装依赖；中途失败后重试可能一直缺包 | 共用依赖检查脚本逐项检查requirements及版本，支持保留环境后重试安装；Windows支持只有PATH中的Python3.11时创建环境 |
| 环境检查 | 原`--check`仅能确认YAML有效，无法解释新电脑缺哪些资源 | 新增离线检查Python、依赖版本、Node/npm、前端依赖、配置、模型和数据文件，逐项提供处理办法，支持JSON报告 |
| 前端依赖与启动 | 已有node_modules不代表上次安装完整或与锁文件一致，启动中间阶段提示较少 | 检查安装完成标记和锁文件指纹，必要时重新安装；启动显示五个阶段，并提供错误与日志入口 |
| 配置正确性 | 非字符串系统提示及部分小数参数能保存，错误延后到推理或启动时暴露 | 保存前要求系统提示为字符串，token数量、滑窗、线程数和端口使用整数；保留有效配置与原默认值 |
| 评测历史 | 固定只取最近50个任务，每次列表更新携带全部报告JSON | 新增分页、总数和摘要模式；页面每页20个任务，选中后按需读取完整报告，仍支持旧客户端读取完整列表结果 |
| 页面更新 | 慢请求可能叠加；过时详情可能覆盖新选择；后台标签仍发起轮询 | 等待前次更新结束后再安排下一次轮询，页面隐藏时暂停，忽略过时响应；常规管理请求使用20秒超时，推理请求保留15分钟等待 |
| 文档日志 | 页面使用折叠组件但未注册，段落详情可能无法正常展开 | 补齐ElCollapse和ElCollapseItem注册，验证实际展开后的段落内容 |
| 使用文档 | 新用户需要先穿过较长的论文实验说明才能找到安装方式 | README顶部新增入口，补充独立的新电脑安装、登录、关闭与排障指南，并更新API契约与AGENTS中的检查说明 |

新增问题用例在修改前复现15项失败；针对真实缺陷与新增接口加入32项测试，包括原生Windows批处理的中断重试、保留已有环境及只读检查。

- **343项pytest通过，1项集成测试排除**；保留1条已有Starlette弃用提示。

- 使用独立SQLite数据库和65个合成历史任务完成页面检查：20条分页、第四页历史访问、详情切换竞争、5.5秒慢响应下轮询最大并发1、隐藏页面暂停、390px手机布局及文档段落折叠。页面未出现运行错误或未注册组件告警。
